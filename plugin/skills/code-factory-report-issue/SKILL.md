---
name: code-factory-report-issue
description: Capture suspected Code Factory defects for an ordinary GitHub issue draft or an existing retained issue conversation.
---

Capture the observed behavior, expected result, reproduction steps and nonsecret
version information. Use an installed GitHub issue skill to prepare a concrete
issue draft when requested. Publish only under the user's instruction to file it.

For an already synchronized issue, use `session_chat` with that canonical item ID
to continue its retained conversation. Code Factory no longer supplies an automatic
investigation/filing pipeline or a separate retained-review report API. Never call
retired reporting tools, copy credentials into evidence, or infer that filing a
report authorizes implementing its fix.
