# Widgets and elements

[Entity model](README.md) · [Panes](panes.md) · [Pages](pages.md) ·
[Connections](connections.md) · [Source/tests](references.md)

Element names in **bold** define scoped element IDs, for example
`W-MESSAGE.text`. Labels in quotation marks are current user-facing labels.
Collections repeat by their item, run, request or configuration key. Settings “Save” means an explicit submission. The item priority picker saves each selection immediately.

## Shared shell

<!-- specs:widgets-0 -->
| Widget | Elements | States and inputs | Outputs/connections |
| --- | --- | --- | --- |
| `W-IDENTITY` | **connection** status only. | Normal Connected status is screen-reader-only. Connecting/disconnected feedback is visible in navigation; the CF mark and application-name brand block are absent. | Connection feedback only; errors remain actionable in the shared alert. |
| `W-NAVIGATION` | Issues **inbox**, **my-prs**, **review-prs**, **messages** with conditional **attention-count**, **current** and contextual **back**. | Four compact tabs; Messages counts only live pending blocking requests and hides zero. Settings has no entry. | Each queue retains its own query and Back context. Messages opens the waiting list instead of choosing a request automatically. |
| `W-GLOBAL-ERROR` | **message** alert; **dismiss** exists for action errors only. Persistent poll feedback clears automatically when polling recovers. | Action errors remain until dismissed or a later successful action. Background poll errors are separate and clear on read recovery; recovered polling never clears a mutation failure. | Dismiss clears the displayed error without repairing the operation or dismissing a dialog. |
| `W-CONNECTION-BLOCKER` | **connecting** status and persistent **blocker** feedback while reads retry. | Initial handshake failures are retried with a fresh bridge instance. Transient failures show Reconnecting; repeated failures show automatic-retry feedback. Success clears only connection/read feedback. | Known read operations retry bounded transient transport failures; startup polling keeps retrying instead of retaining a rejected initialization promise. No credentials or reconnect-consent prompt is introduced. |

## Inbox and item detail

<!-- specs:widgets-1 -->
| Widget | Elements | States and inputs | Outputs/connections |
| --- | --- | --- | --- |
| `W-INBOX-QUERY` | **search** and **filter** in one compact row. | Matches search against title and identifier, without case sensitivity; combines it with the selected filter. | Filters the current focused queue with independent per-tab query state; selecting a row replaces the list with chat. |
| `W-SYNC-HEALTH` | Repository **error** with **repository-id**. | Only repository synchronization failures are rendered. Routine success times and sync-detail disclosures are absent. | Failures remain visible on Inbox; diagnostics provide additional service checks. |
| `W-ITEM-ROW` | Primary row **select**, **title**, **id**, **priority**, **unread-dot**, optional **kind** PR, **state** when not open, **draft**, **new-badge**, **acted-on**. The displayed **id** is the **source-link** to the original issue or PR when a source URL exists; otherwise it is plain text. The priority badge precedes the title inside the selection button, aligned with its first line; it is absent from metadata. | Compact full-width rows with title and relevant metadata; author and routine open-state labels are omitted. Read/New/action indicators remain independent. Wrapping titles keep priority to the left at wide and narrow widths. | Opens PAGE-AGENT and removes the list from the active surface. Back restores list context and row focus when available. The repository/number source link sits in row metadata outside the selection button, opens the saved original URL through the host and never selects or marks the item read. Host denial/failure shows an error without leaving the list. |
| `W-INBOX-EMPTY` | **no-matches** and **clear-filters**, or a concise empty/configuration status. | No matching items offers Clear filters. A configured empty inbox shows No items yet; no repositories shows No repositories configured. No configuration form or inline Settings navigation is offered. | Clear filters restores the full list. Repository configuration is available in its own settings view. |
| `W-ITEM-OVERVIEW` | **loading**, **title** once, compact **id**/**state** and optional PR **kind**, nonempty **body**. Local **read-error** feedback and a **retry** button for nontransport failures. | Item summary and context on the conversation page. Transient loading failures retry with bounded backoff while Back remains available; stale responses are ignored. Tool/business failures require explicit Retry loading item. | Shows the matching item title, identifier and a source-description excerpt above chat; full description is available in Item details. A successful matching read clears its own failure before the displayed revision is marked read. |
| `W-ITEM-ACTIONS` | Secondary **launch** New run plus **unread**, **acknowledge** and **record-action** under Item details. | New run and the priority picker are secondary controls under Item details. Unread, acknowledge and record action remain under Actions. | New run opens the optional prepared review; ordinary item selection already opens chat. |
| `W-PRIORITY` | **override** picker and **save-status** beside the work action; **priority**, **source**, **rationale-or-error** under Priority details. | Automatic displays the effective priority. Saved overrides initialize the picker, including P0. Changes save immediately and failure restores the previous value. Assessment failures remain visible; routine rationale is disclosed. | Each selection changes only the local override. Automatic clears it, restoring label/inference precedence. Provider labels are untouched. |
| `W-RELATIONSHIPS` | Repeated **target**, **evidence-or-local** description, conditional **remove** button; **target-input** required text; **add** button. | Collapsed Relationships disclosure in the item column; opens when returning to an item with an unsubmitted target draft. Manual links retain Remove. | Target drafts stay by item across page changes. Add clears only unchanged submitted text; Add/Remove refresh the active item. The list remains absent while acting on an item. |
| `W-TICKET-CONTEXT` | Repeated **ticket-id**, **summary-or-error**, **status**. | Present for available linked ticket records; failures are text in the same display. | Display only; a ticket identifier is not a clickable ticket page in this UI. |
| `W-PR-EVIDENCE` | Conditional **head**, **branch**; **checks-disclosure** and **checks-content**. | Head/branch appear when present; checks use an expandable details section. | Expands/collapses checks locally. No separate PR/checks page. |
| `W-ITEM-HISTORY` | **activity** rows: kind/author/body; **action-history** rows: kind/time; section headings. | Activity and personal action history have separate collapsed disclosures, hidden when empty. Reference-only activity is omitted. Independent read/New/action state is retained. | Display only. Successful item mutations refresh visible action history; read, New and action indicators remain independent. |

## Agents

<!-- specs:widgets-2 -->
| Widget | Elements | States and inputs | Outputs/connections |
| --- | --- | --- | --- |
| `W-RUN-ROW` | Whole-row **select**, **profile** and creation time within the owning item; **draft-launches** disclosure for prepared rows. | Retained conversations are scoped to the selected item and carry no activity badge. Prepared drafts appear newest first under Draft launches. | Selecting history changes the retained conversation within the item page. Selecting a draft reopens its existing immutable review. No selection starts work. |
| `W-RUN-EMPTY` | **no-runs** empty-state message. | The selected item has no retained work history, or its conversation has no messages yet. | History stays attached to the selected work item. |
| `W-RUN-CONTROLS` | **task-title** and visible **run-error**; **details** holds **profile-name**, **interrupt**, technical activity, **workspace**, **cleanup-effect** and **cleanup**. Activity appears only in the work item status widget. | No Resume control or standalone agent activity header. Interrupt is secondary while a turn is active; cleanup is secondary for idle/interrupted/failed sessions. | Explicit interrupt and cleanup refresh the snapshot on success or failure. Dirty cleanup preserves files and history; a later message restores the same session. Action errors and drafts remain visible. |
| `W-ATTENTION-NOTICE` | Whole-notice **answer** button; **blocking-label** or **continuing-label**. | Repeated for pending requests belonging to the selected run. | Opens `D-ATTENTION` for that request. Nonblocking requests do not imply a stopped agent. |
| `W-TRANSCRIPT` | Human-facing **live-region** Conversation with Agent/You messages and readable errors, repeated **block-label**/**block-text**, **waiting**, **loading-more**, **restart-history** and **read-error**. Commands, plans, diffs, internal summaries and raw output are **technical-activity** under Details; structured **error-details** are there too. | The normal conversation contains agent progress/final messages, user replies and readable errors only. Delta updates merge by message ID, and completed text replaces partial text. A technical-only running stream shows Waiting for an agent update. Details is collapsed initially and stays closed through updates. Read failures retain output/drafts and clear local read feedback after recovery. | Details reveals retained technical activity without starting or changing agent work. Pending question/approval controls remain outside the collapsed data. History paging/reset and the 1,000-event retained limit remain unchanged. |
| `W-MESSAGE` | **text** “Message agent” textarea; **send** button. | Send is disabled while submitting, for blank text, or in prepared/queued/starting/cleaned states. Idle/running/waiting/interrupted/failed sessions accept messages. | Active messages require the displayed expected turn. Inactive messages atomically claim and restore the retained session, using the submitted message as its first continuation turn. The UI never calls Resume separately. Only accepted sends clear unchanged text; errors preserve drafts and no mutation is automatically replayed. |
| `W-WAITING-ROW` | Owning item **title**, identifier, request **question**, reply/approval **state** and **select**. | Pending blocking requests with a live waiting/running owning session only. No requests shows No messages waiting for you. | Selecting opens the owning conversation and exact answer dialog. Answering removes only that request; approval choices preserve exact payloads. |
| `W-NEW-CHAT` | Prefilled editable **message**, profile/mode/permissions/publishing **authority**, explicit **start**, **check-status** and inline **error**. | Per-item draft, busy, prepared retry and uncertain states persist across navigation. Start is disabled while busy/unknown. | Start prepares the visible message once and starts the retained proposal. Changed authority requires another explicit Start. Lost responses read that run before offering retry; late results do not navigate another item. |
| `W-WORK-STATUS` | Compact **value** in issue/PR metadata. | Not started, Starting, Active, Waiting for you, Inactive, Failed or Finished; pending blocking input takes precedence. Item lists use the newest retained unfinished conversation, falling back to cleaned history only when no unfinished run remains, matching item-open selection. | Display only; no separate activity control or Resume action. |

## Launch dialog

<!-- specs:widgets-3 -->
| Widget | Elements | States and inputs | Outputs/connections |
| --- | --- | --- | --- |
| `W-DIALOG-FRAME` | **heading**, **close**, contextual **item** or **blocking-status**; dialog-local **response-error** for launch/attention; attention-only **open-chat**. | Each modal receives initial focus on its first visible enabled control, contains Tab/Shift+Tab, responds to Escape and restores a connected opener. Polling retains current focus; replacing focused controls recovers focus inside the dialog. Dialogs fit within the iframe at narrow widths, with internal vertical scrolling. | Close and Escape dismiss without submitting or starting. Focus stays inside the dialog, including disclosure summaries; it returns to a connected opener or the owning run when the opener disappears. Attention identifies item title and profile. |
| `W-LAUNCH-EDITOR` | **profile** select, **task-prompt** textarea, **model** input, **effort** select, **base** input, repeated **skills** checkboxes; **workspace-policy**, **approval-policy**, **publishing-authority** descriptions; **review** button. | Shown only after Edit. Profile and task remain visible; model/effort/base/skills are under Advanced. Profile selection updates prompt/model/effort/skills. Mode/permissions/publishing remain profile settings. | Review prepares a new snapshot from edited values. Field changes alone do not start work; default launch bypasses the editor. |
| `W-LAUNCH-REVIEW` | **profile**, **mode**, **workspace**, **branch-and-base**, **permissions**, **publishing**, **skills**, **prepared-prompt**; **edit**, **start**, conditional **check-status**. | Default launch opens this prepared review directly. Profile/task/mode/permissions/publishing come from the prepared snapshot. Start and Edit disable while submitting or while acceptance remains unverified. | Explicit Start is required. A failed or lost response reads the same run: accepted work opens in Agents, still-prepared work permits another explicit Start, unavailable status leaves Check start status. Draft reopening reuses the same snapshot. Closing retains prepared records. |

## Attention dialog

<!-- specs:widgets-4 -->
| Widget | Elements | States and inputs | Outputs/connections |
| --- | --- | --- | --- |
| `W-QUESTIONS` | Repeated **question** legend; **options** radio labels/descriptions; conditional **answer-text** or **secret-answer** input; **submit-answer**. | Text input appears for no options or an Other-enabled question; secret text uses a password field. No radio choice is automatically selected. Submit disabled while busy or any question lacks a value. | Sends one response containing all questions. Success refreshes and closes the dialog; stale/invalid responses remain an inline error. |
| `W-APPROVAL` | **request-details** rendered as **command**, **reason**, **requested-access** fields; **technical-details** disclosure; **deny**, **approve-requested-for-turn**, **available-decision** buttons. | Allow once, Allow for this session, Deny and Cancel label the original choices. Permission grants remain requested-only for the turn. Raw payload stays collapsed; submission disables choices. | Readable labels preserve exact original decision objects/strings and permission payloads. No broader permission editor is offered. |
| `W-ELICITATION` | **message**; URL mode: **open-authorization**, **continue**; form mode: repeated **field-title**, **description**, and **boolean-answer**, **enum-answer**, **multi-enum-answer**, **number-answer**, **email-answer**, or **text-answer** plus **submit-form**; unsupported form: **native-support-notice**; always **decline**, **cancel**. | Uses supported schema constraints for required scalar/select fields, numeric bounds and string lengths. A schema-less unsupported request displays a native-host-support notice. Do not infer complete schema support or complete required-field handling for every field type. | URL opens through the host. Continue reports completion without verifying the external authorization itself. Form submits entered values; Decline/Cancel submit their corresponding decisions. Busy disables response submissions, not the external-open button. |

## Settings

<!-- specs:widgets-5 -->
| Widget | Elements | States and inputs | Outputs/connections |
| --- | --- | --- | --- |
| `W-REPOSITORY-SETTINGS` | Repeated **repository-summary**; **repository** required input, **checkout**, **default-base**, **save**, **discover-skills**. **save-result** beside each form. | Checkout/base optional. Summary shows checkout or managed clone plus error/Connected. Saving disables the form; success or an exact error appears beside it; failed inputs remain. | Repositories opens initially and focuses the first input when none is configured. Saving stays in the dedicated settings view, refreshes the summary and displays Saved; discovery has independent feedback. |
| `W-POLICY-SETTINGS` | Repeated **priority-labels** label/priority rows with **add-label**/**remove-label**, **assessment-prompt**, **notifications**, **save**, **save-result**. | Collapsed initially. Each label maps to P0/P1/P2/P3; empty or duplicate labels are rejected inline. Saving disables the form; success/errors stay beside it. | Save changes policy/configuration, invalidating dependent assessments. The notifications checkbox is not a subscription-management UI and cannot make an unsupported host subscribe. |
| `W-PROFILE-SETTINGS` | **existing-profile** select; **new**; **name**, **prompt-template**, **model**, **effort**; **mode**, **sandbox**, **approval**, **publishing** selectors; repeated **default-skills**; **save**. **save-result** beside each form. | Mode: Default/Plan. Sandbox: read-only/workspace-write/danger-full-access. Approval: on-request/untrusted/never. Publishing: ask/authorized. Effort is free text here. Name required. Saving disables the form; success or an exact error appears beside it; failed inputs remain. | New replaces the draft with profile defaults; selection loads an existing profile. Save persists for future preparation, not already-prepared snapshots. |
| `W-SKILL-SETTINGS` | **managed-skill** select with Create a skill option; **name** required input; **instructions** text area; **save**. **save-result** beside each form. | Existing choices include managed skills only. Selecting an existing skill loads name/content. Selecting Create a skill currently does not reset populated fields. Saving disables the form; success or an exact error appears beside it; failed inputs remain. | Save creates/replaces managed skill content. No delete, rename migration or file-tree editor is present. |
| `W-DIAGNOSTICS` | **check-connection** button; conditional **version**, **timestamp**, repeated **check-state**, **check-id**, **detail**; **provider-sign-in-help**. | Initially no result. Results distinguish verified, failed and unverified. Checking disables its button; completion or error appears beside it. | Explicitly requests diagnostics; it neither starts sign-in nor repairs a connection. No in-flight disabling is currently specified. |

## Auxiliary owned surfaces

These appear outside the embedded shell. Their private session fields are
implementation/session data, not user-entered specification elements.

<!-- specs:widgets-6 -->
| Widget | Elements | States and inputs | Outputs/connections |
| --- | --- | --- | --- |
| `W-PACKAGE-OVERVIEW` | **branding**, **version**, **capability-summary**, **portable-download**, **checksum**, **privacy-notice**. | If a valid observed registration exists, the browser package is the primary download. Otherwise connection steps lead. Portable packages and manifests remain in collapsed Advanced packages & manifests. | Registration is looked up when rendering; invalid/missing mappings never promote an unbound browser ZIP. Downloads do not install or authenticate a host. |
| `W-CONNECTION-GUIDE` | **browser-steps**, **endpoint**, **browser-package-download**, **portable-package-help**, **manifest**, **connection-config**, **release-details** links. | OAuth/owner connection steps remain visible. Portable help/manifests/configuration/release links are under Advanced. | Connect through explicit host registration and private OAuth consent; no invented remote ID or automatic install. |
| `W-OWNER-CONSENT` | **connection-heading**, **client-name**, **callback-destination**, **owner-access-warning**, **allow** “Connect Code Factory”, **deny** “Cancel”. | Only a valid owner/private request sees the form. Expired, invalid or unrelated-owner requests return error pages. | Allow or Deny consumes the request and redirects to its registered host callback. No credential field. |
| `W-LOCAL-TUNNEL-KEY` | **heading**, **restricted-key-help**, hidden-then-visible **key** password field, **save-and-start**, **status**. | Alternate tunnel setup only. Form revealed after local reachability/session verification; expires and accepts a submission once. | Clears the input on submit, displays result, removes form on success. | `W-BROWSER-LAB` | **sign-in-boundary-notice**, **screenshot**, **location** summary, **url**, **navigate**, **refresh**, **text-to-send** password field, **send-text**, **key-controls**, **scroll-up/down**, **message**. | Optional developer/operator lab with separate profile and private access. User controls sign-in. | Controls the isolated browser; screenshot click selects coordinates. This tool is not a page or settings pane of the product inbox. |
