## Remaining limits

- Relationship/ticket identifiers remain displayed text.
- An item read can remove its row from an unread-filtered list. Back preserves the filter and falls back to Search focus when that row is absent; Clear filters restores the full list.
- Settings drafts end on remount; Create a skill still retains populated skill fields.
- Ordinary item/run drafts end when the app closes or reloads. They are separate from durable prepared launches and conversation history.
- Fixture focus containment, approval payloads and narrow-layout checks do not establish screen-reader, manual contrast or installed-host acceptance.
- Notification configuration and attention shortcuts do not establish host subscriptions or callbacks. The [acceptance ledger](../acceptance.md) keeps those checks separate.
